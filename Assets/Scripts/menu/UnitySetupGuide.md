# Инструкция по настройке ретро меню в Unity

## ✅ Исправленные проблемы:

### 1. **Убрано окрашивание текста кнопок в зеленый**
- Скрипт больше НЕ меняет цвет текста кнопок
- Текст сохраняет цвета, которые вы настроили в Unity Inspector

### 2. **Исправлена проблема с видео фоном**
- Добавлен задержанный запуск видео
- Используется Camera Far Plane для отображения на фоне
- Видео должно теперь корректно воспроизводиться

### 3. **Убрано подчеркивание текста кнопок**
- Скрипт больше НЕ добавляет подчеркивание
- Текст сохраняет стиль, настроенный в Unity

### 4. **Настроен эффект наведения**
- При наведении текст становится черным и моргает
- Показывается прямоугольник 700x70 цвета #43FCBD
- При уходе курсора все возвращается к исходному состоянию

## 🔧 Настройка в Unity:

### 1. **Для каждой кнопки меню:**

1. **Добавьте скрипт `RetroButton`** к каждой кнопке
2. **Настройте ссылки в Inspector:**
   - **Button**: сама кнопка
   - **Button Text**: TextMeshPro компонент с текстом
   - **Button Image**: Image компонент кнопки
   - **Selection Background**: Image компонент 700x70 с цветом #43FCBD

3. **Настройте Selection Background:**
   - Создайте Image объект как дочерний элемент кнопки
   - Размер: 700x70
   - Цвет: #43FCBD (0.26, 0.99, 0.74, 1)
   - Позиция: за кнопкой (меньший Order in Layer)
   - Изначально неактивен

### 2. **Для VideoBackground:**

1. **Добавьте скрипт `VideoBackground`** к объекту с VideoPlayer
2. **Настройте VideoPlayer:**
   - **Source**: Video Clip
   - **Video Clip**: menu_screen.mp4
   - **Render Mode**: Camera Far Plane
   - **Target Camera**: Main Camera
   - **Target Camera Alpha**: 1

### 3. **Для RetroMainMenu:**

1. **Настройте ссылки:**
   - **Continue Button**: кнопка "Продолжить"
   - **New Game Button**: кнопка "Новая игра"
   - **Settings Button**: кнопка "Настройки"
   - **Exit Button**: кнопка "Выйти"
   - **Selection Background**: Image 700x70 с цветом #43FCBD

2. **Настройте сцены:**
   - **Game Scene Name**: "day1_e"
   - **Settings Scene Name**: "Settings" (если есть)

### 4. **Проверьте настройки текста:**

1. **В TextMeshPro компонентах кнопок:**
   - Убедитесь, что цвет текста настроен как нужно
   - Убедитесь, что нет подчеркивания в Font Style
   - Используйте шрифт "menu SDF"

### 5. **Проверьте иерархию объектов:**

```
Canvas
├── Video Background (с VideoPlayer и VideoBackground скриптом)
├── Menu Panel
│   ├── Continue Button (с RetroButton скриптом)
│   │   └── Selection Background (Image 700x70, #43FCBD)
│   ├── New Game Button (с RetroButton скриптом)
│   │   └── Selection Background (Image 700x70, #43FCBD)
│   ├── Settings Button (с RetroButton скриптом)
│   │   └── Selection Background (Image 700x70, #43FCBD)
│   └── Exit Button (с RetroButton скриптом)
│       └── Selection Background (Image 700x70, #43FCBD)
└── Main Menu Manager (с RetroMainMenu скриптом)
```

## 🎮 Ожидаемое поведение:

1. **При запуске**: Видео фон воспроизводится
2. **При наведении на кнопку**: 
   - Текст становится черным и моргает
   - Показывается прямоугольник #43FCBD
3. **При уходе курсора**: Все возвращается к исходному состоянию
4. **При клике**: Кнопка слегка уменьшается и возвращается

## 🐛 Если что-то не работает:

1. **Видео не воспроизводится:**
   - Проверьте, что VideoPlayer настроен на Camera Far Plane
   - Убедитесь, что файл menu_screen.mp4 находится в папке UI
   - Проверьте, что Target Camera установлен на Main Camera

2. **Кнопки не реагируют на наведение:**
   - Убедитесь, что у кнопок есть EventTrigger компонент
   - Проверьте, что Selection Background настроен правильно

3. **Текст все еще меняет цвет:**
   - Убедитесь, что используете обновленный скрипт RetroButton
   - Проверьте, что в RetroMainMenu не настроены ссылки на тексты кнопок
