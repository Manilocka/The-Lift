# Простая настройка меню - только моргающий текст

## ✅ Упрощенная версия без прямоугольника

### Что убрали:
- ❌ Прямоугольник выделения
- ❌ Сложная логика позиционирования
- ❌ Множественные скрипты

### Что оставили:
- ✅ Моргающий текст при наведении
- ✅ Простая настройка
- ✅ Минимум компонентов

## 🔧 Настройка в Unity:

### 1. **Для каждой кнопки:**
1. **Добавьте скрипт `SimpleTextBlink`** к кнопке
2. **Настройте ссылку:**
   - **Button Text**: TextMeshPro компонент с текстом
3. **Настройте параметры:**
   - **Blink Color**: черный (0, 0, 0, 1)
   - **Blink Speed**: 0.1 (скорость моргания)

### 2. **Для главного меню:**
1. **Добавьте скрипт `RetroMainMenu`** к объекту меню
2. **Настройте ссылки на кнопки:**
   - Continue Button
   - New Game Button
   - Settings Button
   - Exit Button
3. **Уберите ссылку на Selection Background** (оставьте пустой)

### 3. **Для видео фона:**
1. **Настройте VideoPlayer** как обычно
2. **Убедитесь, что видео воспроизводится**

## 🎮 Ожидаемое поведение:

### **При наведении на кнопку:**
- Текст становится черным и моргает
- Никаких прямоугольников

### **При уходе курсора:**
- Текст возвращается к оригинальному цвету
- Моргание останавливается

### **Навигация клавиатурой:**
- Стрелки вверх/вниз для выбора
- Enter/Space для подтверждения

## 📋 Иерархия объектов:

```
Canvas
├── Video Background (VideoPlayer)
├── Menu Panel
│   ├── Continue Button (SimpleTextBlink)
│   ├── New Game Button (SimpleTextBlink)
│   ├── Settings Button (SimpleTextBlink)
│   └── Exit Button (SimpleTextBlink)
└── Menu Manager (RetroMainMenu)
```

## 🐛 Если не работает:

1. **Проверьте ссылки** в Inspector
2. **Убедитесь, что Button Text назначен** в SimpleTextBlink
3. **Проверьте, что Enable Blinking = ✓** в RetroButton (если используете)
