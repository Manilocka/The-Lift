# Настройка ретро главного меню

## Пошаговая инструкция по настройке главного меню в стиле старого компьютера

### 1. Настройка сцены Game menu

1. Откройте сцену `Game menu.unity`
2. Удалите все существующие объекты (если есть)

### 2. Настройка камеры с fish eye эффектом

1. Создайте пустой объект `Main Camera`
2. Добавьте компонент `Camera`
3. Добавьте скрипт `RetroCamera`
4. Настройте параметры:
   - Fish Eye Strength: 0.3
   - Chromatic Aberration: 0.1
   - Vignette: 0.3
   - Noise: 0.05
   - Scanlines: включить
   - Tint Color: зеленый (0.2, 1, 0.2, 1)

### 3. Настройка видео фона

1. Создайте пустой объект `Video Background`
2. Добавьте компонент `Video Player`
3. Добавьте скрипт `VideoBackground`
4. Настройте Video Player:
   - Source: Video Clip
   - Video Clip: menu_screen.mp4
   - Render Mode: Render Texture
   - Target Texture: создайте новый Render Texture (1920x1080)

### 4. Создание UI Canvas

1. Создайте Canvas (UI > Canvas)
2. Настройте Canvas:
   - Render Mode: Screen Space - Overlay
   - UI Scale Mode: Scale With Screen Size
   - Reference Resolution: 1920x1080

### 5. Создание кнопок меню

1. Создайте панель для кнопок (UI > Panel)
2. Создайте 4 кнопки (UI > Button):
   - Продолжить
   - Новая игра
   - Настройки
   - Выйти

3. Для каждой кнопки:
   - Добавьте скрипт `RetroButton`
   - Настройте цвета (зеленый ретро стиль)
   - Добавьте TextMeshPro компонент для текста
   - Настройте шрифт: menu SDF

### 6. Настройка текстов

1. Создайте TextMeshPro объекты для каждого пункта меню
2. Настройте шрифт: menu SDF
3. Цвет: зеленый ретро
4. Размер: подходящий для ретро стиля

### 7. Настройка главного скрипта меню

1. Создайте пустой объект `Menu Manager`
2. Добавьте скрипт `RetroMainMenu`
3. Настройте ссылки:
   - Кнопки меню
   - Тексты меню
   - Видео плеер
   - Аудио источники

### 8. Настройка ретро эффектов

1. Создайте Image для эффекта сканирования
2. Создайте Image для эффекта глитча
3. Настройте их как overlay на Canvas

### 9. Настройка аудио

1. Добавьте AudioSource к Menu Manager
2. Настройте звуки:
   - Select Sound: звук выбора
   - Confirm Sound: звук подтверждения

### 10. Финальная настройка

1. Настройте разрешение: 1920x1080
2. Проверьте все ссылки в скриптах
3. Протестируйте навигацию клавиатурой и мышью
4. Настройте переходы между сценами

## Дополнительные настройки для ретро эффектов

### Сканирующие линии
- Создайте материал с шейдером для сканирующих линий
- Настройте анимацию движения линий

### Глитч эффекты
- Настройте случайные вспышки
- Добавьте хроматическую аберрацию

### Цветовая коррекция
- Зеленый оттенок для ретро монитора
- Контраст и яркость в стиле старых экранов

## Тестирование

1. Запустите сцену
2. Проверьте навигацию стрелками
3. Проверьте клики мышью
4. Убедитесь, что все эффекты работают
5. Проверьте переходы между сценами
