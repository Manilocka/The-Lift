# ВОССТАНОВЛЕНИЕ СКРИПТОВ ДЛЯ НАСТРОЕК

## ✅ ВОССТАНОВЛЕНЫ ВСЕ СКРИПТЫ:

### **1. RetroSettingsMenu.cs** - Основное меню настроек
- **Полная функциональность** меню настроек
- **Навигация клавиатурой** и мышью
- **Сохранение настроек** в PlayerPrefs
- **Ретро эффекты** (сканирование, глитч)

### **2. SimpleButton.cs** - Простые кнопки
- **Автоматическое подключение** к Button компоненту
- **Поддержка переходов** между сценами
- **Звуковые эффекты** при нажатии
- **Отладочные сообщения** для проверки

### **3. SimpleSlider.cs** - Простые слайдеры
- **Автоматическое сохранение** в PlayerPrefs
- **Применение настроек** сразу
- **Отображение значений** в тексте
- **Простая настройка** через Inspector

### **4. ExitButton.cs** - Кнопка выхода
- **Простой выход** из игры
- **Поддержка звуков**
- **Работает в редакторе** и в билде

## 🔧 ЧТО НУЖНО СДЕЛАТЬ В UNITY:

### **1. Для RetroSettingsMenu:**
1. **Выберите объект** с "Missing (Mono Script)"
2. **В Inspector нажмите** на поле "Script"
3. **Выберите RetroSettingsMenu** из списка
4. **Настройте все ссылки** согласно вашей иерархии

### **2. Для кнопок:**
1. **Добавьте SimpleButton** к каждой кнопке
2. **Настройте параметры:**
   - **Is Back Button**: ✓ для кнопки "Назад"
   - **Target Scene Name**: имя сцены для других кнопок

### **3. Для слайдеров:**
1. **Добавьте SimpleSlider** к каждому слайдеру
2. **Настройте параметры:**
   - **Setting Key**: "Volume"/"Brightness"/"MouseSensitivity"
   - **Value Text**: ссылка на текст значения

### **4. Для кнопки "Выйти":**
1. **Добавьте ExitButton** к кнопке "Выйти"
2. **Настройте звуковые эффекты** (опционально)
