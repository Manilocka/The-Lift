# Простая система диалогов с вложенными репликами

## Как работает новая система

Теперь внутри каждого `Choice` можно вставлять реплики как в обычном диалоге. Это полностью исключает путаницу между вариантами.

## Структура DialogueLine

```csharp
public struct DialogueLine {
    public string speakerName;
    public string text;
    public bool isPlayer;
    public bool isThought;
    public List<Choice> choices;
}
```

## Структура Choice

```csharp
public struct Choice {
    public string choiceText;                    // Текст выбора
    public List<DialogueLine> dialogueLines;     // Список реплик для этого выбора
}
```

## Пример использования

### Создание диалога:

```
Строка 0: "О чем хотите поговорить?"
├── Выбор 1: "О работе"
│   ├── Реплика 1: "Расскажи о своей работе"
│   ├── Реплика 2: "Это интересно!"
│   └── Реплика 3: "Спасибо за рассказ"
├── Выбор 2: "О личном"
│   ├── Реплика 1: "Как дела дома?"
│   ├── Реплика 2: "Понимаю..."
│   └── Реплика 3: "Береги себя"
└── Выбор 3: "О хобби"
    ├── Реплика 1: "Какие у тебя увлечения?"
    ├── Реплика 2: "Звучит увлекательно!"
    └── Реплика 3: "Обязательно попробую"

Строка 1: "Спасибо за интересную беседу!" (автоматически после любого выбора)
```

### Настройка в Unity:

1. Создайте DialogueSO
2. Добавьте строку с выбором:
   - `text`: "О чем хотите поговорить?"
3. Для каждого выбора:
   - `choiceText`: "О работе"
   - `dialogueLines`: Добавьте список реплик
     - Реплика 1: "Расскажи о своей работе"
     - Реплика 2: "Это интересно!"
     - Реплика 3: "Спасибо за рассказ"
4. Добавьте следующую строку: "Спасибо за интересную беседу!"

## Преимущества новой системы:

✅ **Простота**: Каждый выбор содержит свои реплики  
✅ **Изоляция**: Полная изоляция между вариантами  
✅ **Наглядность**: Сразу видно, какие реплики к какому выбору относятся  
✅ **Гибкость**: Легко добавлять/удалять реплики в любом выборе  
✅ **Безопасность**: Нет путаницы между вариантами  

## Как это работает:

1. Игрок выбирает опцию
2. Система показывает реплики только этого выбора
3. После окончания реплик диалог автоматически переходит к следующему элементу
4. Другие варианты полностью изолированы
5. Никаких дополнительных настроек не требуется
6. Максимальная простота использования

## Отладка:

Система выводит логи:
- `"Показываем X реплик для выбора 'текст'"`
- Предупреждения при отсутствии реплик
- Ошибки при проблемах с навигацией
